# Assessment approach

This MVP uses a single Next.js App Router application with focused server routes, keeping the implementation easy to understand and deploy within an eight-hour assessment. The browser accepts PDF, PNG, and JPEG files, while the extraction route validates both metadata and file signatures before processing uploads in memory. Selectable PDF text is extracted with `pdf-parse`; images are processed with Tesseract.js OCR. Extracted text is shown to the user before analysis so the source remains inspectable.

The analysis route keeps the Groq API key server-side, sends a concise content-editing prompt, requests JSON, and validates the response with Zod before rendering it. Firebase Authentication and Firestore provide account-scoped profiles, feedback, and analysis history. Friendly status and error states cover extraction failures, empty text, missing configuration, unavailable AI, and malformed responses. The interface uses a short set of genuine workflow states—reading, analyzing, and saving—so loading feedback reflects active requests rather than simulated progress. Responsive Tailwind components provide keyboard-accessible upload, visible focus treatment, and scan-friendly result cards.
